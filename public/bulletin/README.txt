Put files you want to attach to a bulletin in this folder (PDF, DOCX, images).
Use simple names: lowercase, hyphens instead of spaces, no accents or brackets.
Example: opin-kinsulai.pdf

Then mention the file name in src/data/bulletins.js:   file: 'opin-kinsulai.pdf'
(For a picture shown inside the bulletin use:           image: 'my-picture.jpg')

Anything in this folder is PUBLIC once the site is deployed.
